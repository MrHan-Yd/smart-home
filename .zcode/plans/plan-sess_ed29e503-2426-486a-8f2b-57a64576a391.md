# 现代化 UI 升级方案（玻璃质感 + 渐变 · 全局样式）

## 目标
把当前"扁平表单感"升级为现代 SaaS / Apple Home 风格：玻璃拟态顶栏与卡片、柔和渐变背景、发光状态点、分层阴影、悬停微上浮、更克制的留白与层级。**只动样式，不改组件结构**，所有页面自动受益。

## 范围
- 主战场：`frontend/src/styles/prototype.css`（全局 token + 通用类）
- 配套微调：3 个 scoped 样式块（AppToast、DeviceControls、AppShell）+ `style.css` 补 `.muted` 全局类
- 不改任何 `.vue` 模板结构、不改后端

## 设计基线
- 已有 shadcn 风格 token（`--background/--card/--border/--primary` 等）保留并扩展
- 已有的 `.dc-hero`（设备详情 hero 渐变）和 `.wall-*`/`.hud-*`（分析大屏玻璃拟态）作为视觉参照，把那种质感下放到全局通用组件
- 暗色为主，亮色同步；尊重现有 `data-theme` 切换

## 具体改动（按文件）

### 1. `prototype.css` — token 扩展
- 新增 token：`--glass`（卡片半透明底）、`--glass-border`（半透明白边）、`--shadow-sm/-md/-lg`（三层阴影体系）、`--ring`（聚焦光环色）、`--grad-primary`（主渐变）、`--grad-bg`（页面背景渐变）
- 暗色：`--glass: 222 22% 10% / 0.6`，`--glass-border: 0 0% 100% / 0.06`
- 亮色：`--glass: 0 0% 100% / 0.7`，对应调整

### 2. `prototype.css` — 通用类升级
| 类 | 现状 | 升级 |
|----|------|------|

| `.sidebar` | 半透明 | 玻璃底 + 右侧渐变分隔线 |
| `.nav-item` | hover 变 muted 底 | hover 加左侧 2px primary 指示条 + 微亮底；active 加柔和 primary 渐变底 + 发光 |
| `.bottom-nav` | 纯色 | 玻璃底 + 顶部渐变分隔线，active 图标 primary 发光 |
| `.btn` | 扁平 | 加 `transition` 含 transform；hover `translateY(-1px)`；`.btn-primary` 用 `--grad-primary` 渐变底 + 柔和阴影；`.btn-outline` hover 加 primary 边光晕 |
| `.btn-icon` | 圆形 | hover 加旋转/微缩放 |

| `.device-card` | 扁平卡 | 玻璃底 + hover 上浮 + 边光晕；`.on` 状态加柔和绿色内发光；`.ico` 用渐变底；`.state-text.on` 发光 |
| `.toggle` | 纯色开关 | `.on` 用绿色渐变 + 滑块柔和阴影；transition 加弹性 |
| `.chip` | 扁平药丸 | active 用 primary 渐变底 + 发光；hover 微亮 |
| `.input`/`.select` | 扁平输入 | 玻璃底 + 聚焦光环（`box-shadow: 0 0 0 3px var(--ring)`）+ 渐变边 |
| `.section-title` | 灰色大写 | 加左侧 2px primary 竖条 + 渐变文字可选 |
| `.empty` | 虚线框 | 玻璃底 + 柔和虚线 + 内部图标占位渐变 |
| `.page-header h1` | 纯文字 | 加渐变文字（primary → 紫） |
| `.login-panel` | 扁平卡 | 玻璃底 + 强阴影 + 边缘高光 |
| `.panel` / `.dc-card` / `.discover-item` / `.scen-card`(scoped) / `.settings-card`(scoped) | 扁平 | 玻璃底 + 分层阴影 + hover 上浮（仅交互型） |

| `.user-chip`/`.avatar` | 静态 | avatar 渐变发光环 |
| `.badge` | 灰底 | 玻璃底 + 微阴影 |

### 3. 全局动效（新增 keyframes）
- `@keyframes pulse`（状态点呼吸）、`@keyframes floatUp`（卡片入场，替代现有 fadeIn）、`@keyframes glow`（active 发光）
- 现有 `@keyframes fadeIn` 升级为带轻微 scale 的入场

### 4. `style.css` — 补全局 `.muted`
- 新增 `.muted { color: hsl(var(--muted-foreground)); }`（目前 `.muted` 只在各 scoped 块定义，SettingsView 动态用到但无全局兜底）

### 5. scoped 同步（保持视觉一致）
- **`AppToast.vue`** `.toast`：升级为玻璃底 + 模糊 + 阴影 + 左侧 2px 状态色条（ok 绿/err 红）
- **`DeviceControls.vue`** `.dc-card`：同步玻璃底 + 阴影（与全局 `.dc-card` 一致）
- **`AppShell.vue`** `.nav-item`/`.bottom-nav a`：保持与全局 nav 升级一致的 active/hover 表现（左侧指示条 + 渐变底）

### 6. 滚动条美化（可选小项）
- `::-webkit-scrollbar` 细条 + 半透明滑块 + hover 变亮

## 不在范围
- 不改任何 `.vue` 模板/结构/逻辑
- 不引入组件库、不引入图表库
- 不改分析 HUD（`.hud-*`/`.wall-*` 已是玻璃拟态，保持原样）
- 不改后端

## 验证
- `npx vue-tsc --noEmit` 通过
- 本地 `npm run dev` 肉眼检查：总览/设备列表/设备详情/房间/场景/分析/设置/登录完成页，确认暗色与亮色两套主题都正常
- 检查移动端响应式（窄屏）未被新阴影/渐变破坏

## 风险与回滚
- 全部集中在 CSS，回滚只需还原 `prototype.css` + 3 个 scoped 块
- 主要风险：玻璃拟态在低性能设备上 `backdrop-filter` 略卡 → 已有 `@media (hover:none)` 降级钩子，会同步为触屏降级
- 渐变文字（`background-clip:text`）需 `-webkit-` 前缀，会带上
