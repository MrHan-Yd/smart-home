# 智能家居子系统 — 功能设计

> 定位：**自用**智能家居门户 — 管设备、看状态、能控制、看历史与简单分析。  
> 路线：设备接入靠 **Home Assistant**；登录靠 **统一认证中心**；本系统做业务门户。  
> 相关：[架构设计.md](./架构设计.md) · [技术选型.md](./技术选型.md) · [认证接入设计.md](./认证接入设计.md)

---

## 1. 产品边界

| 要做 | 不做 |
|------|------|
| SSO 登录后的设备总览与控制 | 替代米家/厂商 App **配网、加设备** |
| 实时/近实时状态监控 | 自研各品牌私有协议适配 |
| 历史曲线与使用分析（开多久、几次等） | Keep 等无开放 API 的健康硬件强接 |
| 房间/备注/收藏等轻量整理 | 多租户 SaaS、家庭成员复杂 RBAC（初期） |
| 对接 **一套** HA API | 语音助手原生技能、商城、社区 |
| 与统一认证中心 SSO / 切换系统 | 本系统自建账号密码 |

「设备」在本系统中的含义：优先展示 HA 已接入的实体（entity）；用户可做备注、房间归属、隐藏，**不在本系统完成首次配网**。

## 2. 用户与认证

| 功能 | 说明 | 阶段 |
|------|------|------|
| SSO 登录 | 统一认证中心，授权码 + PKCE | P0 |
| 本地会话 | Cookie + Redis；token 只来自认证中心 | P0 |
| 无感刷新 | 服务端单飞 refresh | P0 |
| 当前用户 | `GET /api/v1/me` | P0 |
| 登出 | 清本地会话；可选 IdP revoke | P0 |
| 切换系统 | 跳认证中心 `/select-system`（保留 SSO） | P0 |
| 本地用户缓存 | 首次登录按 `sub` upsert | P0 |

规则：未登录不可访问业务 API；**不**用 HA Token 当用户身份。

## 3. 家庭与 HA 连接

自用默认 **一个用户 ↔ 一个家庭 ↔ 一个 HA 实例**；模型预留扩展。

| 功能 | 说明 | 阶段 |
|------|------|------|
| 默认家庭 | 登录后自动有默认 home（或首次引导） | P0 |
| HA 连接配置 | 服务端保存 `base_url` + Long-Lived Token（加密/密钥引用） | P0 |
| 连接探测 | 检测 HA 是否可达、API 是否可用 | P0 |
| 连接状态展示 | 前端显示「已连接 / 断开 / 未配置」 | P0 |
| Token 安全 | 前端**永不**下发明文 Token；设置页最多显示「已配置」 | P0 |
| 多 HA（可选） | 多实例切换 | 暂缓 |

管理员式配置：自用可由环境变量注入 HA（更简单），或设置页表单写入（更灵活）。**P0 推荐环境变量 + 只读状态接口**，设置页表单可 P1。

## 4. 设备管理（核心）

> **多类型扩展设计（发现/纳入/能力注册表/统一控制）见专文：**  
> [设备类型与接入设计.md](./设备类型与接入设计.md)

### 4.0 添加设备（多类型，跟 HA 走）

| 功能 | 说明 | 阶段 |
|------|------|------|
| 发现 | 从 HA 拉取 entity，形成「可添加」列表（非本系统配网） | P0 |
| 纳入 | 单选/批量将 entity 加入「我的设备」 | P0 |
| 类型覆盖 | **HA 有的 domain 均可添加**；未知类型至少只读展示 | P0 |
| 控制覆盖 | 按 TypeProfile **分期**实现（先 light/switch 开关，再 climate/cover…） | P0 起持续 |
| 移除 | 仅从本系统移除，不影响 HA 侧设备 | P0 |
| 能力驱动 UI | 前端按 `capabilities[]` 渲染控件，便于加新类型 | P0 骨架 |

原则：**添加面 = HA 能力上限；控制面 = 本系统注册表已实现部分。**  
扩展新类型 ≈ 注册 domain→能力 + action 映射 +（可选）控件，不改主流程。

### 4.1 设备列表与展示

| 功能 | 说明 | 阶段 |
|------|------|------|
| 我的设备列表 | 仅已纳入设备 + 实时/缓存状态 + capabilities | P0 |
| 设备卡片 | 名称、类型图标、当前状态、所属房间（若有） | P0 |
| 类型识别 | HA domain → TypeProfile / 图标 / 能力 | P0 |
| 筛选 | 按房间、domain/类型、关键词、仅收藏、仅可控制、在线 | P0～P1 |
| 隐藏实体 | 发现黑名单 + 用户隐藏（如系统 helper） | P1 |
| 备注/显示名 | 覆盖 HA `friendly_name` 的本地显示名 | P1 |
| 收藏 | 置顶常用设备 | P1 |
| 详情页 | attributes、能力控件、最近状态摘要 | P0～P1 |

### 4.2 设备控制

| 功能 | 说明 | 阶段 |
|------|------|------|
| 统一 actions API | `POST .../actions { action, params }`，与 domain 解耦 | P0 |
| 开关类 | light / switch / input_boolean：`turn_on`/`off`/`toggle` | P0 |
| 亮度/色温/彩色 | light 扩展能力（有 attr 才暴露） | P1 |
| 空调/气候 | climate：模式、目标温度等 | P1 |
| 窗帘/遮盖 | cover：开合、位置 | P1 |
| 按钮 | button / input_button：`press` | P1 |
| 场景/脚本 | scene / script 激活（可当设备或独立入口） | P2 |
| 播放器/扫地机等 | media_player、vacuum… | P2 起按需 |
| 只读类 | sensor / binary_sensor / 未映射 domain：无控制按钮 | P0 |
| 执行反馈 | 成功/失败提示；可选返回最新 state | P0 |
| 防连点 | 前端禁用 + 可选幂等键 | P0 |

控制统一走本系统 → 服务端 **Capability 校验** → HA `POST /api/services/...`。  
**禁止**前端拼 HA URL。

### 4.3 房间与整理

| 功能 | 说明 | 阶段 |
|------|------|------|
| 房间列表 | 客厅/卧室等（本地维护或同步 HA area） | P1 |
| 设备归房间 | 手动指定或跟随 HA area | P1 |
| 按房间浏览 | 总览页分区 | P1 |

P0 可不做房间，扁平列表即可。

## 10. 权限（极简 · 自用）

| 规则 | 说明 |
|------|------|
| 已登录 | 可访问本系统业务 API |
| 设备范围 | 仅当前用户绑定 home 下的 HA 实体 |
| 他人数据 | 无多用户分享时不涉及；若扩展须按 home 隔离 |
| HA 凭证 | 仅服务端；用户不能通过 API 读出 Token |

初期 **不做**：家庭成员邀请、只读访客、设备级 ACL。

## 11. 非功能需求

| 项 | 要求 |
|----|------|
| 安全 | OAuth 契约；secret/HA token 不出前端；日志脱敏 |
| 可用 | HA 断开时页面可用但明确降级（只读缓存或提示不可控） |
| 性能 | 列表接口避免无脑全量 attributes 过大；可裁剪字段 |
| 一致 | 控制后尽快反映新状态（再拉 state 或 WS） |
| 部署 | Go 单二进制 + Vue SPA；HA 常开主机另署 |

## 14. 功能清单（验收视角）

### P0 必验

- [ ] 未登录访问业务页 → 走 SSO，登录后回到本系统  
- [ ] `/api/v1/me` 返回当前用户  
- [ ] HA 在线时，**发现列表**能看到 HA 中实体（黑名单除外）  
- [ ] 可将 light/switch **添加**到「我的设备」并执行开/关  
- [ ] 可将 sensor 或未知 domain **添加**为只读展示  
- [ ] 从本系统移除后可再次添加  
- [ ] HA 未配置或断开时，有明确提示，不白屏  
- [ ] 前端网络面板中无 HA Token、无 client_secret  

### P1 建议验

- [ ] 历史曲线能画出至少一类数值传感器或开关时段  
- [ ] 本地显示名/隐藏生效且刷新后仍在  
- [ ] 控制失败有可读错误  

### P2 建议验

- [ ] 分析页有次数或时长类指标  
- [ ] 状态变更无需整页刷新即可更新（WS 或可接受的短轮询）

## 15. 明确排除（避免范围膨胀）

1. 设备配网向导、扫描蓝牙/Zigbee  
2. 自研米家/涂鸦云协议  
3. Keep 体脂秤等封闭生态  
4. 完整替代 HA 的自动化编辑器  
5. 视频监控存储与回放中台（摄像头可仅嵌 HA 或外链，不做录像平台）  
6. 商业多租户、计费、App 上架
