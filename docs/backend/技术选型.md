# 智能家居子系统 — 技术选型

> 总体架构：[架构设计.md](./架构设计.md)  
> 认证接入：[认证接入设计.md](./认证接入设计.md)

---

## 1. 已定结论

| 层 | 选型 | 说明 |
|----|------|------|
| **后端语言** | **Go 1.22+** | 与 ProjectManagement（`pm-service`）对齐 |
| 服务形态 | 单体 BFF `smart-home-service` | 单进程；不拆微服务 |
| 身份 | 统一认证中心 OAuth2/OIDC | 不自签 Token |
| 设备接入 | Home Assistant HTTP（后续 WS） | 半自研，不自写厂商协议 |

---

## 2. 为何选 Go

1. 与 PM 同为「业务子系统」：OAuth 回调、JWKS、Redis session、refresh 单飞可复用同一套结构  
2. 对接 HA 以 I/O 为主（REST / WebSocket），Go 标准库足够  
3. 单二进制部署，自用运维简单  
4. 避免再引入 Node/Java 第三套业务语言（IdP 已是 Rust，子系统统一 Go）

---

## 3. 后端依赖（建议）

| 用途 | 库 | 备注 |
|------|-----|------|
| HTTP | `net/http` 或轻路由（chi 等） | 与 PM 保持一致风格即可 |
| PostgreSQL | `jackc/pgx/v5` | 用户、设备映射、同步水位 |
| Redis | `redis/go-redis` | session、JWKS 缓存、refresh 锁 |
| JWT | `golang-jwt/jwt/v5` | 校验 IdP RS256 |
| UUID | `google/uuid` | 本地主键；IdP `sub` 为字符串存 |
| 配置 | `joho/godotenv` + 环境变量 | 同 PM |
| HA 客户端 | 自研 `internal/adapter/hass` | 薄封装，无重型 SDK |

**P0 不上：** ORM 全家桶、消息队列、gRPC、Influx 强制依赖。

---

## 4. 数据与中间件

| 组件 | 选型 | 用途 |
|------|------|------|
| 主库 | PostgreSQL | users、homes、entity 映射、审计 |
| 缓存 | Redis | 会话、锁、短期状态缓存 |
| 时序 | P0 读 HA history；P2 再定 Timescale 或继续 PG | 避免过早引入第二套时序栈 |
| 对象存储 | 暂不需要 | 无源文件场景（与 PM 不同） |

---

## 5. 与 HA 的集成方式

| 能力 | 协议 | Go 实现要点 |
|------|------|-------------|
| 状态列表 | REST `GET /api/states` | `http.Client` + Bearer Token |
| 控制 | REST `POST /api/services/{domain}/{service}` | JSON body，`entity_id` |
| 历史 | REST `GET /api/history/period` | query 参数 |
| 实时 | WebSocket（P2） | 官方 WS API，服务端订阅再推前端 |

HA Long-Lived Token **仅**服务端配置，不进前端。

## 6. 目录约定（与 PM 同构）

```
backend/
├── cmd/server/
├── configs/
├── internal/
│   ├── auth/           # OAuth、JWKS、session、refresh
│   ├── middleware/
│   ├── module/
│   │   ├── home/
│   │   ├── device/
│   │   ├── history/
│   │   └── analytics/
│   ├── adapter/hass/   # Home Assistant 客户端
│   ├── pkg/
│   └── infra/          # pg、redis
├── migrations/
├── go.mod
└── .env.example
```

模块名建议：`github.com/demo/smart-home/backend`（可按仓库调整）。

## 7. 开发端口（建议，避免冲突）

| 服务 | 端口 |
|------|------|
| 认证中心 API | 3000 |
| 认证中心前端 | 5173 |
| ProjectManagement API | 3001 |
| **smart-home API** | **3002** |
| smart-home 前端（后续） | 5175 等 |

`OAUTH_REDIRECT_URI` 示例：`http://127.0.0.1:3002/oauth/callback`

## 8. 明确不做（后端）

- 自签 access/refresh  
- 浏览器持有 HA Token / client_secret  
- P0 全自研米家/涂鸦协议  
- Keep 等无开放 API 设备强接
