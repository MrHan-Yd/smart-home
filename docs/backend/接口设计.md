# 智能家居子系统 — 接口设计

> 认证：Session Cookie（BFF）；Token 仅来自统一认证中心  
> 设备：经服务端调 HA（见 [HA对接设计.md](./HA对接设计.md)）  
> 风格对齐 ProjectManagement 子系统

---

## 1. 通用

| 项 | 约定 |
|----|------|
| API Base | `/api/v1` |
| OAuth | `/oauth/login` · `/oauth/callback` · `/oauth/logout` |
| 健康 | `/healthz` · `/readyz` |
| 协议 | JSON · UTF-8 |
| 鉴权 | 除 login/callback/health 外需登录 Cookie |
| 数据范围 | 仅当前用户 home 下资源 |

### 1.1 统一响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 0 | 成功 |
| 40100 | 未登录 |
| 40300 | 无权限 |
| 40400 | 不存在 |
| 40000 | 参数错误 |
| 40001 | 不支持的 action / 缺少 capability |
| 40900 | 冲突（如 entity 已添加、设备 unavailable） |
| 50200 | HA 不可达 / 认证失败 / 上游错误 |
| 50000 | 内部错误 |

HTTP 状态：业务码与 HTTP 大致对齐（401/403/404/400/409/502/500）。

### 1.2 错误 data 示例

```json
{
  "code": 50200,
  "message": "Home Assistant 不可达",
  "data": { "reason": "ha_unreachable" }
}
```

## 2. OAuth / 当前用户

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/oauth/login` | 302 → IdP authorize；query `return_to` 可选 |

  "home": {
    "id": "uuid",

  }
}
```

| GET | `/api/v1/discover/entities` | 发现池 |

| 参数 | 说明 |
|------|------|

  "already_added": false,
  "capabilities": ["on_off", "brightness", "color_temp"],
  "control_level": "full",
  "device_class": null,
  "area": null
}
```

```json
{
  "items": [ /* ... */ ],
  "page": 1,
  "page_size": 50,
  "total": 120
}
```

### 6.1 列表 Query

| 参数 | 说明 |
|------|------|
| q | 关键词 |
| domain | |
| room_id | |
| favorite | true/false |
| controllable | true → 排除只读 |
| include_hidden | 默认 false |

### 6.2 DeviceView（列表/详情 data）

```json
{
  "id": "uuid",
  "entity_id": "light.living_room",
  "domain": "light",
  "name": "客厅灯",
  "room_id": "uuid|null",
  "room_name": "客厅",
  "favorite": true,
  "hidden": false,
  "state": "on",
  "available": true,
  "primary_display": "开启 · 70%",
  "capabilities": ["on_off", "brightness", "color_temp", "color_hs", "effect"],
  "control_level": "full",
  "attributes": {
    "brightness": 180,
    "color_temp_kelvin": 3200,
    "hs_color": [40, 60],
    "effect_list": ["none", "colorloop"],
    "friendly_name": "客厅灯"
  },
  "ha": {
    "last_changed": "2026-07-24T10:00:00Z",
    "last_updated": "2026-07-24T10:00:00Z"
  }
}
```

列表可将 `attributes` 裁剪为摘要字段以减小体积；详情返回完整 attributes。

### 6.3 纳入

```json
// POST /devices
{ "entity_id": "light.living_room", "name": "可选本地名", "room_id": null }

// POST /devices/batch
{ "entity_ids": ["light.a", "switch.b"] }
```

响应：创建设备对象或 `{ "created": [...], "skipped": [...] }`。

冲突：已存在 → skip 或 `409 already_added`（单加时）。

### 6.4 PATCH

```json
{
  "name": "客厅主灯",
  "room_id": "uuid",
  "favorite": true,
  "hidden": false,
  "sort_order": 10
}
```

## 7. 控制 Actions（核心）

```http
POST /api/v1/devices/{id}/actions
Content-Type: application/json
Idempotency-Key: optional-uuid
```

### 7.1 请求

```json
{
  "action": "turn_on",
  "params": {
    "brightness": 180,
    "transition": 0.5
  }
}
```

| 字段 | 说明 |
|------|------|
| action | 逻辑动作，见下表与 [HA对接设计.md](./HA对接设计.md) §6 |
| params | 可选；键与 HA data 对齐或本系统约定 |

### 7.2 常用 action 与 params

#### 通用开关类（light / switch / fan / climate / media_player…）

| action | params |
|--------|--------|
| `turn_on` | 可带 domain 扩展字段 |
| `turn_off` | `transition?` |
| `toggle` | |

#### light

| action | params |
|--------|--------|
| `set_brightness` | `brightness` 1–255 或 `brightness_pct` 0–100 |
| `set_color_temp` | `color_temp_kelvin` |
| `set_hs_color` | `hs_color`: [h, s] |
| `set_effect` | `effect` |
| 亦允许 | `turn_on` + 上述字段合并 |

#### climate

| action | params |
|--------|--------|
| `set_hvac_mode` | `hvac_mode` |
| `set_temperature` | `temperature` |
| `set_fan_mode` | `fan_mode` |
| `set_swing_mode` | `swing_mode` |
| `set_preset_mode` | `preset_mode` |
| `set_humidity` | `humidity` |

#### cover

| action | params |
|--------|--------|
| `open` / `close` / `stop` / `toggle` | |
| `set_position` | `position` 0–100 |
| `set_tilt_position` | `tilt_position` 0–100 |
| `open_tilt` / `close_tilt` / `stop_tilt` | |

#### fan

| action | params |
|--------|--------|
| `set_percentage` | `percentage` 0–100 |
| `set_preset_mode` | `preset_mode` |
| `set_oscillating` | `oscillating` bool |
| `set_direction` | `direction`: forward/reverse |

#### media_player

| action | params |
|--------|--------|
| `play` / `pause` / `stop` / `next` / `previous` | |
| `set_volume` | `volume_level` 0–1 或 `volume_pct` 0–100 |
| `set_mute` | `is_volume_muted` bool |
| `select_source` | `source` |

#### lock

| action | params | 备注 |
|--------|--------|------|
| `lock` / `unlock` | | unlock 建议要求确认 |

#### vacuum

| action | params |
|--------|--------|
| `start` / `pause` / `stop` / `return_to_base` / `locate` | |
| `set_fan_speed` | `fan_speed` |

#### scene / script / button

| action | domain |
|--------|--------|
| `activate` | scene |
| `run` | script |
| `press` | button |

### 7.3 成功响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "device": { /* 最新 DeviceView */ },
    "ha_service": "light.turn_on"
  }
}
```

### 7.4 失败

- 设备不属于用户 → 404  
- action 不在白名单 → 40001  
- 设备无对应 capability → 40001  
- HA 失败 → 50200

## 8. 历史（P1）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/devices/{id}/history` | 单设备历史 |
| GET | `/api/v1/history` | query `entity_id` 或 `device_id` |

### Query

| 参数 | 说明 |
|------|------|
| start | ISO8601，必填或默认 now-24h |
| end | ISO8601，默认 now |
| significant_only | bool，透传 HA |

### 响应

```json
{
  "entity_id": "sensor.living_temp",
  "points": [
    { "t": "2026-07-24T08:00:00Z", "state": "24.1", "num": 24.1 },
    { "t": "2026-07-24T09:00:00Z", "state": "24.5", "num": 24.5 }

}
```

`num`：可解析为浮点时填充，供图表。

## 13. 前端协作约定

1. 所有业务请求 `credentials: 'include'`  
2. 401 → 跳转 `/oauth/login?return_to=...`  
3. 控制按钮：loading + 可选 Idempotency-Key  
4. **禁止**浏览器请求 HA 地址  
5. 切换系统：跳转 IdP `{AUTH_PORTAL_URL}/select-system`（仅清本地会话观感，不 logout IdP）  

开发端口：API `3002`，前端 `5175`（Vite 代理 `/api` `/oauth`）。
