# 智能家居 UI 原型

纯 HTML / CSS / JS 静态设计稿，对齐 [功能设计](../../backend/功能设计.md) 与 [设备类型与接入设计](../../backend/设备类型与接入设计.md)。

## 打开方式

用浏览器直接打开 `index.html`，或：

```bash
# 任选本地静态服务
npx --yes serve .
```

## 响应式

| 宽度 | 布局 |
|------|------|
| &lt;640px | 手机：底栏导航、2 列设备卡、顶栏精简、详情单列操控 |
| 640–899 | 大手机/小平板：3–4 列卡片，仍用底栏 |
| ≥900px | 侧栏导航 + 主内容 |
| 横屏矮屏 | 压缩顶栏/底栏与大屏 KPI |

含 `safe-area`（刘海/底部横条）、触控热区与分析大屏滚动适配。

## 页面

| 页面 | 说明 |
|------|------|
| 登录 | 模拟统一认证 SSO |
| 总览 | 统计卡片 + 收藏 + 设备墙快捷开关 |
| 设备 | 搜索 / 房间 / domain / 仅可控制·收藏 |
| 添加设备 | HA 发现池、单选/批量纳入、仅监控标识 |
| 详情操作台 | 按 HA domain 完整操控：灯(亮度/色温/HS/灯效/过渡)、空调(模式/温度/风速/摆风/预设/湿度)、窗帘(开合/位置/倾角)、风扇、媒体、锁、扫地机、场景、传感器只读等 |
| 历史 | 曲线占位（正式 ECharts） |
| 分析 | 次数/时长/用电等指标占位 |
| 设置 | HA 状态、Token 脱敏、模拟断开 |
| 分析大屏 | 科技 HUD 风格分析看板（霓虹/网格/扫描线/粒子）：KPI、时长柱图、排行、类型环、环境曲线、时段热力 · Esc 退出 |

## 交互说明

- 所有数据为前端 mock，无真实 HA / 认证请求  
- 主题：右上角 / 顶栏切换，写入 `localStorage` key `sh-theme`  
- 「切换系统」仅 toast 提示  

## 与实现对应

正式前端见 [技术选型](../技术选型.md)：Vue 3 + Tailwind；本目录仅作视觉与信息架构基准。
